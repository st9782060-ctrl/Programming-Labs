## 1. Відповіді на ключові питання

1. **Що таке оператори?**  
   **Оператори** — це спеціальні символи або ключові слова мови програмування, які вказують компілятору, яку саме дію (арифметичну, логічну, присвоєння тощо) потрібно виконати над даними (наприклад: `+`, `-`, `*`, `/`, `=`).

2. **Що таке операнди?**  
   **Операнди** — це дані (змінні, константи, літерали або вирази), над якими виконується дія, задана оператором. Наприклад, у виразі `a + 5` оператором є `+`, а операндами — `a` та `5`.

3. **Які бувають функції?**  
   У мові програмування C++ функції поділяються на:
   * **Стандартні (бібліотечні)** — вбудовані в стандартні бібліотеки мови (наприклад, математичні функції з `<cmath>`: `sin()`, `cos()`, `pow()`, `log()`, `sqrt()`).
   * **Користувацькі** — функції, створені програмістом самостійно для вирішення конкретних підзавдань (включно з головною функцією `main()`).

4. **Як в мові програмування C++ позначається квадратний корінь?**  
   Для обчислення квадратного кореня використовується стандартна функція `sqrt(x)` із заголовного файлу `<cmath>`.

5. **Як в мові програмування C++ отримати остачу від ділення?**  
   Для отримання остачі від цілочисельного ділення використовується бінарний оператор `%` (наприклад, `10 % 3` поверне `1`).
